# 마브 한국어 UI 용어집

마브 화면 문구는 한국어 전용이다. 다국어 라이브러리 없이 코드 안의 문구를 한국어로 직접 쓴다.

## 말투
- 버튼·메뉴·탭·라벨: 명사형으로 짧게 — "저장", "취소", "삭제", "공유", "설정"
- 안내·확인·오류 문장: 해요체 — "노트를 삭제했어요.", "서버에 연결할 수 없어요."
- 질문(확인 대화상자): "이 노트를 삭제할까요?"
- 이모지 쓰지 않는다. 영어는 제품명·기술 용어(MCP, URL, Markdown, PDF, Claude, Codex 등)에만.
- 숫자 복수형 처리(`note${n === 1 ? "" : "s"}`)는 "노트 ${n}개"처럼 단위 하나로.
- 날짜·시간은 한국식("11월 17일", "2분 전").
