# 마이 세컨드 브레인

줄여서 **마브**라고 불러요.

노트가 전부 내 컴퓨터의 `.md` 파일로 저장되는 세컨드 브레인 앱이에요.
파일이 그냥 마크다운이라서, Claude Code 같은 AI가 따로 연결하지 않아도 노트를 바로 읽고 고칠 수 있어요.

## 할 수 있는 것

- 노트는 폴더 안의 `.md` 파일 그대로 저장돼요. 앱을 지워도 노트는 남아요.
- Claude Code가 노트를 고치면 마브 화면에 바로 반영돼요.
- 한국어 검색이 돼요. "세컨브레인을"로 검색해도 "세컨브레인" 노트가 나와요.
- 한글(hwpx)·PowerPoint(pptx) 파일을 앱 안에서 미리 보고, 본문 글자로 검색할 수 있어요.
- 옛날 형식(hwp·doc·ppt·xls)도 목록에 보이고, 버튼 하나로 한글이나 기본 앱에서 열 수 있어요.
- `[[노트 이름]]` 링크, 백링크, 태그, 그래프 보기
- 내 서버에 연결하면 여러 기기·팀원과 실시간으로 같이 고칠 수 있어요. 폴더마다 볼 사람·고칠 사람을 정할 수 있어요.
- 인터넷이 끊겨도 쓸 수 있어요. 다시 연결되면 고친 내용이 합쳐져요.

## 설치하기

### 1. 설치 파일 받기

[Releases 페이지](https://github.com/chatdaeri/mav/releases/latest)에서 내 컴퓨터에 맞는 파일을 받아요.

| 컴퓨터 | 받을 파일 |
|---|---|
| Mac (Apple 칩: M1·M2·M3·M4) | `마이 세컨드 브레인_<버전>_aarch64.dmg` |
| Mac (Intel 칩) | `마이 세컨드 브레인_<버전>_x64.dmg` |
| Windows | `마이 세컨드 브레인_<버전>_x64-setup.exe` |

Mac 칩 확인: 왼쪽 위 사과 메뉴 → 이 Mac에 관하여 → "칩" 항목

### 2. 처음 실행할 때 경고 넘기기

마브는 Apple·Microsoft의 유료 인증(코드 서명)을 받지 않은 앱이라서 처음 열 때 경고가 떠요. 한 번만 허용하면 다음부터는 안 떠요.

**Mac**
1. `.dmg`를 열고 마브를 응용 프로그램 폴더로 끌어다 놓아요.
2. 마브를 열면 "확인되지 않은 개발자" 경고가 떠요. 완료를 눌러 닫아요.
3. 시스템 설정 → 개인정보 보호 및 보안 → 아래쪽 "마이 세컨드 브레인" 항목에서 **그래도 열기**를 누르고 암호를 입력해요.

위 방법이 안 되면 터미널에 아래 한 줄을 붙여 넣고 다시 열어요.

```bash
xattr -dr com.apple.quarantine "/Applications/마이 세컨드 브레인.app"
```

**Windows**
1. 설치 파일을 열면 "Windows의 PC 보호" 창이 떠요.
2. **추가 정보** → **실행**을 눌러요.

### 3. 노트 폴더 열기

마브를 켜고 노트를 둘 폴더를 고르면 끝이에요. 원래 쓰던 마크다운 폴더(옵시디언 볼트 등)를 그대로 열어도 돼요.
혼자 한 기기에서만 쓴다면 여기까지만 하면 돼요. 여러 기기나 팀원과 같이 쓰려면 아래 "서버로 동기화하기"를 이어서 해요.

## 서버로 동기화하기

동기화 서버는 팀마다 직접 띄워요. 챗대리가 운영하는 공용 서버는 없어서, 노트는 내 서버에만 저장돼요.

### 1. 서버 띄우기 (약 5분)

1. [Railway](https://railway.com)에 가입하고 결제 카드를 등록해요. 소규모 팀 기준 월 5달러 안팎이에요(정확한 요금은 Railway 요금 페이지에서 확인).
2. 아래 버튼을 눌러요. 데이터베이스와 서버가 자동으로 만들어지고 `https://○○.up.railway.app` 주소가 생겨요.

   [Deploy on Railway](https://railway.com/deploy/mav-server) <!-- 템플릿 공개 후 실제 주소로 교체 -->

3. 배포가 끝나면 Railway 화면에서 서버 주소를 복사해 둬요.

### 2. 마브 연결하기

1. 마브 첫 화면에서 **내 서버 연결**을 누르고 복사한 주소를 붙여 넣어요.
2. 이메일과 비밀번호로 계정을 만들어요. 처음 만든 사람이 관리자예요.
3. 동기화할 노트 폴더를 골라요.

### 3. 팀원 초대하기

1. 팀원에게 `https://○○.up.railway.app/open/connect` 링크를 보내요. 팀원이 링크를 누르면 마브가 이 서버로 연결돼요.
2. 관리자는 볼트 설정 → 멤버에서 **참여 코드**를 만들어 팀원에게 알려 줘요.
3. 팀원이 가입하고 참여 코드를 넣으면 같은 노트가 내려받아져요.

### 25MB 넘는 파일은 링크로 나눠요

서버는 파일 하나당 25MB까지 동기화해요. 그보다 큰 파일과 영상은 서버에 올라가지 않고 내 컴퓨터에만 남아요. 팀원과 나누려면:

1. 파일을 구글 드라이브에 올리고 공유 링크를 복사해요.
2. 마브에서 그 파일을 열면 나오는 **드라이브 링크 붙여 넣기** 칸에 링크를 넣어요.
3. 같은 폴더에 링크 파일이 생기고, 팀원은 그걸 눌러 드라이브에서 열어요.

## Claude Code로 노트 고치기

터미널에서 노트 폴더로 이동해서 Claude Code를 켜요.

```bash
cd ~/내노트폴더
claude
```

"이번 주 회의록 노트들 요약해서 새 노트로 만들어줘"처럼 말하면 Claude가 폴더 안의 파일을 직접 만들고 고쳐요. 마브가 켜져 있으면 바뀐 내용이 바로 화면에 보여요.

## 영상·큰 파일·임시 파일

| 파일 | 마브에서 |
|---|---|
| 영상(mp4·mov·mkv·webm 등) | 서버에 올리지 않고 이 기기에만 둬요. 팀원과 나누려면 구글 드라이브에 올린 뒤 링크를 붙여 넣어요 |
| 25MB 넘는 파일 | 영상과 같아요 |
| 임시 파일(`.tmp`, `~$`로 시작하는 파일 등) | 목록에 안 보여요 |

## 직접 빌드하기 (개발자용)

### 준비물

- Node.js 22 이상
- corepack: Node 25부터는 따로 설치해야 해요 (`npm install -g corepack` → `corepack enable`)
- Rust & Cargo ([rustup.rs](https://rustup.rs))
- Docker (서버를 띄울 때만)

### 실행

```bash
git clone https://github.com/chatdaeri/mav.git
cd mav/app
pnpm install
pnpm run dev:desktop      # 개발용 앱 실행
pnpm run build:desktop    # 설치 파일 만들기
```

## Railway 대신 내 컴퓨터에 서버 띄우기 (개발자용)

Docker가 깔린 컴퓨터나 NAS에서:

```bash
cd mav/deploy/compose
cp .env.example .env      # POSTGRES_PASSWORD, JWT_SECRET, BETTER_AUTH_URL 세 값을 채워요
docker compose up -d
```

밖에서 접속하려면 HTTPS 설정이 필요해요. 자세한 방법은 [deploy/compose/README.md](deploy/compose/README.md)를 보세요.
